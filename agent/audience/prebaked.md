line from here for a file when the model answers `429 RESOURCE_EXHAUSTED` after
its retries (a brand-new project has a small per-minute quota), or for every
file when `STUDIO_REAL_READERS=0` is set in `.env`. The console says which
lines were prebaked. Nothing else reads this file.
